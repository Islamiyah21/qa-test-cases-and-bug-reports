# QA Test Cases and Bug Reports

## About This Project

This repository demonstrates my approach to manual software testing through test case design and structured defect reporting.

The project uses a fictional banking application to illustrate testing techniques for common financial workflows.

## Project Contents

- **Test-Cases.md:** Sample functional test cases for login, account balance, and fund transfer workflows.
- **Bug-Reports.md:** Illustrative defect reports showing reproduction steps, expected and actual results, severity, and impact.

## Testing Skills Demonstrated

- Test scenario identification
- Test case design
- Positive and negative testing
- Functional testing
- Defect documentation
- Severity and priority assessment
- Expected versus actual result analysis
- Risk-based thinking for financial workflows

## Tools and Documentation

This project uses Markdown for test documentation and GitHub for version control and project organisation.

## Important Note

This is a demonstration portfolio using a fictional application. The test cases have not been executed against a live banking system, and the defects are illustrative examples rather than verified findings.
